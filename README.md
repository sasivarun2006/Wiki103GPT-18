# 1st-project
 An 18.55M-parameter  language model trained from scratch on WikiText-103 using PyTorch.   Features 4 Transformer layers, 4 attention heads, 256-dimensional embeddings, 128-token context length, and a 32K BPE tokenizer.   Implements next-token prediction, training, validation, text generation, checkpointing, and mixed-precision GPU training.
